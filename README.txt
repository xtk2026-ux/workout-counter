운동 카운터 v10

변경 사항
- 카프레이즈 4세트를 운동 목록 맨 위에 추가
- 기존 월·수·금·토 운동일 및 자동 날짜 초기화 유지
- 라잉 트라이셉스 익스텐션은 수요일·토요일만 2세트
- 체중 기록 입력, 날짜별 저장, 추세 그래프 유지
- 체중 CSV 내보내기 추가: 날짜와 체중(kg)만 간단히 저장
- 전체 기록 JSON 내보내기 추가: 체중 기록, 과거 운동 기록, 현재 진행 상황 및 루틴 포함

분석 방법
1. 체중 기록 카드에서 '체중 CSV 저장' 또는 '전체 기록 JSON 저장'을 누릅니다.
2. 내려받은 파일을 이 채팅에 첨부합니다.
3. CSV는 체중 추세·주간 평균·감량 속도 분석에, JSON은 운동량과 체중 변화의 연관 분석에 사용할 수 있습니다.

기존 기록 보존
기존 localStorage 키를 유지하므로 v9까지의 운동·체중 기록은 그대로 이어집니다. 카프레이즈는 새 항목으로 추가됩니다.

GitHub Pages 업데이트
1. ZIP 압축을 풉니다.
2. 저장소의 index.html, manifest.webmanifest, icon.svg, sw.js를 새 파일로 교체합니다.
3. Commit changes를 누릅니다.
4. 삼성 인터넷에서 앱을 새로고침합니다.
